## 📝 Description
This mobile application helps investors calculate their Unit Trust dividends efficiently. It calculates both **Monthly Dividend** and **Total Dividend** based on the invested fund, annual dividend rate, and duration of investment.

## ✨ Features
* **Input Validation:** Ensures months do not exceed 12.
* **Accurate Calculation:** Uses standard formulas with 2 decimal formatting.
* **Responsive UI:** Clean interface with Action Bar and Navigation Menu.
* **Reset Function:** Clears all inputs easily for new calculations.
* **Detailed Output:** Displays both monthly and total dividend results clearly.

## 📊 Example Calculation Logic
This app follows the standard formula provided in the lab requirement:

1.  **Monthly Dividend** = `(Rate / 12) * Invested Fund`
2.  **Total Dividend** = `Monthly Dividend * Number of Months`
